## Atribuir por API

```bash
curl -X POST "$AUTHENTIK_URL/api/v3/rbac/permissions/assigned_by_roles/<role-uuid>/assign/" \n  -H "Authorization: Bearer <admin-token>" -H "Content-Type: application/json" \n  -d @docs/permissions.json
```

O token da conta tem de ser do tipo **API** (o token criado com a conta de serviço é _app_password_ e não serve para a API).
